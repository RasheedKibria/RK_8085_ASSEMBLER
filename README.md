# RK-8085 Assembler
Name: RK-8085 Assembler

Purpose: Converts a source code written in 8085 assembly language into its equivalent machine code which can be loaded into a 8085 microprocessor unit

Feature: Supports the entire 8085 instruction set

Supported OS: Linux (Ubuntu 24.04 Noble)

Command:               ./RK8085 -f source_file_name.asm

Example Command:       ./RK8085 -f ./ADDNBYT.asm
